# 飛機 GO！（Airplane GO!）— Godot 4 3D 飛行模擬遊戲

一款基於 **Godot 4（Forward+）** 開發的 3D 民航飛行模擬與雲層跑酷遊戲，從登機門空橋登機、後推滑行、跑道起飛、點擊閃雲跑酷到進場落地滑回停機坪，提供完整門到門（Gate-to-Gate）飛行體驗。

## 主要特色

- **4 款專屬 3D `.glb` 機型**：
  - **波音 737-800**（短中程靈活型，融合翼尖小翼）
  - **空中巴士 A321neo**（中程主力型，鯊魚鰭小翼）
  - **空中巴士 A330-300**（沉穩寬體型，斜角翼尖小翼）
  - **波音 787-9**（遠程寬體型，後掠式斜削翼尖）
- **6 家原創授權安全塗裝**：
  - **梅花航空**（紅梅白尾塗裝）、**老虎航空**（亮橘黑虎紋）、**星光航空**（曜石金星塗裝）、**CNC 航空**（海天雙藍塗裝）、**桃子航空**（桃紫漸層塗裝）、**長帆航空**（翠綠金橘塗裝）。
- **10 座台日陸實景主題機場**：
  - 高雄小港（KHH）、台北松山（TSA）、台灣桃園（TPE）、澎湖馬公（MZG）、東京成田（NRT）、福岡（FUK）、關西國際（KIX）、沖繩那霸（OKA）、廣州白雲（CAN）、深圳寶安（SZX），依各地特色配置專屬地標、海港或都會建築群。
- **完整流暢流程與玩法**：
  - 登機門立體空橋與旅客登機動態小窗 → 自動後推對準滑行道 → 黃色指引箭頭滑行進跑道 → V1／Vr／V2 中文語音報速起飛 → **點擊閃雲飛機跑酷模式** → 進場綠色引導環、ILS 十字與無線電報高（500／100／50／30／20／10）→ 輪胎觸地白煙反推煞車 → 直接滑回停機坪下機結算。
- **多種天候與雙視角切換**：支援日間、黃昏、夜間、雨天（含駕駛艙動態雨刷與雨絲特效），以及機尾後方／3D 駕駛艙雙圓錶視角切換。

## 執行方式

1. 安裝 **Godot Engine 4.3** 或以上版本。
2. 開啟 Godot Project Manager，點擊 **Import** 並選擇本資料夾內的 `project.godot`。
3. 匯入完成後按下右上角 **Play（F5）** 即可開始遊玩。
