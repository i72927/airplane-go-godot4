一、如何在 Godot 4 開啟並試玩
1. 下載並解壓縮 airplane_go_godot4.zip 到電腦任意英文路徑資料夾。
2. 打開 Godot 4（建議 4.2 或 4.3 以上版本），點選「匯入（Import）」。
3. 選擇資料夾內的 project.godot 後按「匯入並編輯」。
4. 等待約 3 秒讓 Godot 自動匯入 .glb 3D 客機模型與高解析貼圖，直接按 F5 即可全 3D 執飛！

二、操作方式（支援滑鼠觸控按鈕與鍵盤）
- 螢幕觸控 / 滑鼠操作：
  * 左側推力滑桿 /「推滿起飛」/「煞車 / 反推」
  * 中央「📡 塔台聯絡」（亮綠時點擊即播報中文語音並推進流程）、「起落架」、「襟翼」、「雨刷」、「👁 視角切換」
  * 右側四向飛控鍵（俯↓ / 仰↑ / ◀ / ▶）
- 電腦鍵盤快捷操作：
  * W / S：加速 / 減速（油門）
  * 方向鍵 ← / → / ↑ / ↓：轉向與俯仰
  * B：煞車與反推

三、如何自行替換更精細的外部 3D 客機模型（Sketchfab / Blender）
本專案已內建 4 款平滑 3D 客機 .glb 模型，位於 assets/models/：
  - b737_800.glb
  - a321_neo.glb
  - a330_300.glb
  - b787_9.glb
若你之後在 Sketchfab 等網站下載了免費高精細民航機 .glb 檔案，只要將檔名改成上述對應名稱並直接覆蓋 assets/models/ 內的檔案（確認機頭朝向 -Z 軸），重新開啟 Godot 4 就會自動套用新模型，完全不必修改任何程式碼！
